# 🚀🌮 Postacos Project

TacoPOS is a sleek and efficient point-of-sale (POS) application designed for taco restaurants, food trucks, and taquerias. This app streamlines order management, enhances customer experience, and optimizes kitchen workflow.
---

## 🛠️ Tech Stack

**Client:**  
- NextJs  
- Tailwind CSS  

**Server:**  
- NestJs  
- postgres

**Tools:**  
- Turborepo 
- Docker

---

## 📦 Installation

```bash

#Install docker image and setup DB

# Clone the repo
git clone https://github.com/PahesebPJ/pos-tacos.git
cd pos-tacos

# Install dependencies
npm install

# Setup environment (create a .env file)

# Run project
npm run dev
